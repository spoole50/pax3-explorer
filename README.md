# Ember · PAX 3 remote

A single-page Web Bluetooth remote for the PAX 3.

**Live:** https://spoole50.github.io/pax3-explorer/

## Use on iPhone
1. Install [Bluefy](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055) (Safari/Chrome on iOS have no Web Bluetooth).
2. Close the official PAX app so it isn't holding the connection.
3. Open the live URL in Bluefy, turn on **Developer mode**, enter your 8-character serial (saved locally on the device only).
4. Tap **Connect** and pick your PAX.

Works on desktop Chrome/Edge too. Must be served over HTTPS (or localhost).
